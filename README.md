# IT Home Lab

A collection of hands-on IT labs documenting real-world T1 helpdesk tasks and system administration work. All labs were performed on live systems — no simulations.

## Lab Environment
- **Host Machine:** Dell Inspiron 14 7420 2-in-1, Windows 11 Home
- **Virtualization:** Oracle VirtualBox
- **Server:** Windows Server 2012 R2 (matching production environment)
- **Domain:** lab.local
- **Domain Controller:** Lab-DC01

## Skills Demonstrated
- Active Directory administration — OUs, users, groups, GPOs, password resets, account lifecycle
- Domain Controller deployment — AD DS, DHCP, DNS configuration on Windows Server 2012 R2
- Network diagnostics — ipconfig, ping, tracert, nslookup, DNS flushing
- Windows Server administration — services management, event log analysis, file sharing
- File permissions — NTFS permissions, network shares, least privilege principle
- Helpdesk ticketing — documentation, prioritization, escalation
- Cybersecurity awareness — phishing recognition, social engineering defense
- Remote support — AnyDesk workflow and best practices
- PowerShell — service management, disk queries, system reporting

## About
Self-directed home lab built to gain hands-on T1 IT experience. Labs 01, 03, 04, 10 and 12 were performed on a live Windows Server 2012 R2 Domain Controller running in VirtualBox — matching the production environment at the target workplace. All remaining labs were performed on a physical Windows 11 host machine.
