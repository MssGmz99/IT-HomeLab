# IT Home Lab

A collection of hands-on IT labs documenting real-world T1 helpdesk tasks and system administration work. All labs were performed on live systems.

## Lab Environment
- **Host Machine:** Dell Inspiron 14 7420 2-in-1, Windows 11 Home
- **Virtualization:** Oracle VirtualBox
- **Server:** Windows Server 2012 R2 (matching production environment)
- **Domain:** lab.local

## Labs Completed

| Lab | Topic | Platform |
|---|---|---|
| Lab 01 | Active Directory — Domain Controller Build | Windows Server 2012 R2 VM |
| Lab 02 | User Account Management | Windows 11 Host |
| Lab 03 | Network Connectivity Troubleshooting | Windows 11 Host |
| Lab 04 | Windows Event Viewer | Windows 11 Host |
| Lab 05 | Task Manager & Resource Monitoring | Windows 11 Host |
| Lab 06 | Disk Management & Storage | Windows 11 Host |
| Lab 07 | Printer Troubleshooting | Windows 11 Host |

| Lab 11 | System Information Tools | Windows 11 Host |

## Skills Demonstrated
- Active Directory administration — OUs, users, groups, GPOs, password resets
- Domain Controller deployment — AD DS, DHCP, DNS configuration
- Network diagnostics — ipconfig, ping, tracert, nslookup, DNS flushing
- Windows system administration — services, event logs, disk management
- Helpdesk ticketing — documentation, prioritization, escalation
- Cybersecurity awareness — phishing recognition, social engineering defense
- Remote support — AnyDesk workflow and best practices

## About
Self-directed home lab built to gain hands-on T1 IT experience. Every task was performed on real hardware and live systems to simulate actual helpdesk scenarios.
